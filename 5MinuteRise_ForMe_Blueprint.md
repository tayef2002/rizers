## 🤖 AI DAILY PLAN

### কীভাবে কাজ করবে:
- **Launch phase:** Rule-based (user data pattern দেখে pre-written plan)
- **Month 2-3:** Real Claude API integration
- User এর data: habit history + namaz record + sleep pattern + goals → Personalized plan
- User নিজে customize করতে পারবে
- প্রতিদিন সকালে auto-generate

### Plan structure:
```
ফজর → সকালের routine → Deep Work Block 1 → 
যোহর → Lunch + Rest → Deep Work Block 2 → 
আসর → Personal time → মাগরিব → 
Evening routine → এশা → ঘুম
```
